## Lessons from the last session (recorded 2026-10-13)

1. **A tolerance written before measurement is a fabricated number in a gate.** The
   landing tolerance was first written as a guessed 0.9%; the first real run measured
   13%. Measure, record with the numbers and their sources, then enforce. If you have
   not run the measurement, the field stays `deferred`.
2. **Full-page captures of two documents differ in height as a matter of course.** The
   first real compare failed with "dimensions differ" — the harness being wrong, not the
   app. `diffPixels` now compares the overlap and prints both sizes; do not "fix" a
   dimension failure by normalising the screenshots.
3. **`*/` inside a glob inside a JSDoc comment terminates the comment early.**
   `` scripts/**/*.mjs `` in `apps/web/eslint.config.mjs`'s header broke the file at
   load. Third recorded instance of a declaration parser reading a comment body
   (with the `AC-2's` and `--warn:` cases). Avoid `*/` sequences in comments.
4. **PowerShell 5.1 traps, both hit today:** `'x'.repeat(64)` does not exist (`'x' * 64`
   does); and `Regex.Replace(input, pattern, replacement, 1)` is **not** count-limited —
   the `1` binds to `RegexOptions.IgnoreCase` and replaced *every* occurrence (a WORKLOG
   entry got inserted five times). Use `String.Insert` with `IndexOf`, or back up and
   restore with `git checkout --`.
5. **`playwright` is not resolvable from a root script**; `@playwright/test` is
   `apps/web`'s direct dependency. That is why the capture lives in
   `apps/web/scripts/` and the pure core in `scripts/`.
6. **ESLint `no-undef` fires for `.mjs` files** even though TS files are exempt. Node
   scripts need a globals block — see the `scripts/**/*.mjs` block in
   `apps/web/eslint.config.mjs`, following `apps/api`'s prisma/erd precedent. Browser
   globals (`document`, `window`) are declared there because `page.evaluate` callbacks
   run in the page.
7. **Run `npx prettier --write` on new `.mjs`/`.json` before committing.** The
   pre-commit hook checks them; `docs/**/*.md` is still exempt (2026-10-11 rationale
   unchanged). A stray `index.json.tmp` from an experiment was caught by
   `git diff --cached --name-only` — keep doing that check.
8. **A bash-less environment bites in small ways:** `tail`/`head` pipes fail on this
   PowerShell; use `Select-Object -First/-Last`. Direct `.mjs` imports need `file://`
   URLs on Windows (`node -e "import('H:/...')"` fails with `ERR_UNSUPPORTED_ESM_URL_SCHEME`).
9. **The e2e flake to watch for:** one run exited 1 with no test output (the shape of a
   webServer-startup failure) and did not reproduce across three clean runs. Nothing in
   `test-results/`, `.last-run.json` passed. If it recurs, the shape points at dev-server
   boot, not the app — and kill any leftover dev server on port 3500 first.
