## 5. Traps hit today — the same ones will recur

- **A glob inside a JSDoc comment silently ends the comment.** `**/` contains `*/`. Prettier then
  reports the error on the _following_ line. Third occurrence in this repo.
- **`prisma db push` applies the Prisma schema only.** `prisma/hardening/*.sql` is never run.
- **A suffix include matches a longer suffix.** `include: ['src/**/*.spec.ts']` also collects
  `*.integration.spec.ts`. Unit and integration suites are now explicitly disjoint.
- **Two hashers cannot verify each other's output.** Never seed a password before `PLT-101` owns
  `IPasswordHasher`.
- **PowerShell `if (native-command)` tests stdout, not the exit code.** `-q` flags print nothing,
  so every such check reads as failure. Use `$LASTEXITCODE`.
- **A measurement is not a finding.** Check whether a test already asserts the opposite before
  recommending a change.
- **Commit or fetch first.** `git fetch` before reading the working tree for what exists.
