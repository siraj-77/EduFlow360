UML Sequence Diagrams UML

Two representative flows: secured login with lockout, and attendance marking through to a parent alert.

sequenceDiagram
  actor U as User
  participant UI as Web/App
  participant API as Auth API
  participant Guard as PermissionGuard
  participant DB as Postgres
  participant Audit as AuditRecorder

  U->>UI: enter email + password
  UI->>API: POST /auth/login
  API->>DB: find user + check lock status
  alt locked (5+ fails in window)
    API-->>UI: 429 Too Many Attempts
  else valid credentials
    API->>DB: verify password hash
    API->>API: issue access + refresh tokens
    API->>Audit: log LOGIN_SUCCESS
    API-->>UI: 200 + tokens
    UI->>Guard: subsequent requests carry token
    Guard->>Guard: resolve role → permissions (cached)
  else invalid credentials
    API->>DB: increment failed-attempt counter
    API->>Audit: log LOGIN_FAILED
    API-->>UI: 401 generic error
  end

sequenceDiagram
  actor T as Teacher
  participant UI as Web/App
  participant ATT as Attendance Service
  participant DB as Postgres
  participant JOB as Absentee Detector (cron)
  participant NOT as Notification Router
  actor P as Parent

  T->>UI: mark class attendance
  UI->>ATT: POST /attendance (bulk)
  ATT->>ATT: validate ownership (own class only)
  ATT->>DB: write AttendanceRecord rows
  ATT->>DB: write AuditRecord (if regularized)
  Note over JOB: scheduled window closes
  JOB->>DB: query unmarked/absent students
  JOB->>NOT: send ABSENCE_ALERT events
  NOT->>NOT: resolve channel (email default)
  NOT-->>P: absence notification

Foundation (licence, settings, roles) Academic & people Finance & GL Operational modules Migration → launch

Rule of thumb: nothing that references a parent record can be entered before that parent exists — you cannot assign a fee structure (⑰) to a student (⑫) that doesn't exist yet, and you cannot allocate a class (⑭) before sections (⑦) exist. Steps ⑥–⑨ (Academic Structure) and ⑯–⑰ (Chart of Accounts / Fee Structures) are the two long poles: almost everything else depends on one of them. Full step-by-step detail is in EduFlow360_School_Setup_Workflow_v1.md.
